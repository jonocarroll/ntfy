# Emoji

Emoji symbols available in ntfy

## Usage

``` r
emoji
```

## Format

### `emoji`

A data frame with 7,240 rows and 60 columns:

- emoji:

  Symbol

- aliases:

  Name of the emoji that can be used in a `tag`

- tags:

  Alternative names

- category:

  Category

- description:

  Description

- unicode_version:

  Unicode Version
